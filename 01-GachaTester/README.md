# 基于python的抽卡模拟器及测试demo
模拟抽卡机制，支持档位数量与概率配置、保底逻辑、抽卡记录存储。
使用pytest编写自动化测试，用于练习测试设计与实现能力。
## 功能
1. 指定抽数抽卡；
2. 软保底、硬保底；
3. 卡池档位、概率配置；
4. 抽卡记录写入文件；
5. pytest自动化测试
## 项目结构
```python
    GachaTester

    ├─gacha
  
    │  │  core.py             #抽卡核心逻辑
  
    │  │  result.txt          #抽卡结果存储（运行生成）
  
    │  │  characters.json     #卡池与概率配置

    │  │  __init__.py

    ├─test
    
    │  │  test_gacha.py       #抽卡执行函数测试
    
    │  conftest.py            #pytest配置文件
  
    └─README.md
```
